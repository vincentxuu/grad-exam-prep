### 關鍵結論

1. **兩校考科重疊度極高**：計概（台大叫「資訊科技概論」、政大叫「計算機概論」）與 MIS（台大叫「資訊管理導論」、政大叫「管理資訊系統」）是共同科目。
2. **主攻「台大 + 政大資管組」的組合，只需準備四科**：計概、MIS、統計、英文(B)。統計只有台大考、資料結構只有政大科技組考。
3. **想再加政大科技組**，就是多背一科資料結構，其餘完全共用。
4. **兩校二階都很重**：台大口試 40%、政大面試 50%。政大甚至面試分數是同分參酌的第一順位。筆試只是入場券。

## 三、逐科準備指南

### 3.0 台大三科內容地圖（優先級與取捨）

先看分數結構——它決定投資比例。台大三科中資訊科技概論與資訊管理導論**各加權 100%**，英文(B) 不加權，換算後：

| 科目 | 佔筆試 | 佔總成績（筆試 60%） |
| --- | --- | --- |
| 資訊科技概論 | 40% | 24% |
| 資訊管理導論與統計學 | 40% | 24% |
| 英文(B) | 20% | 12% |
| 口試 | — | 40% |

#### 資訊科技概論

題型：選擇題（**答錯倒扣**）＋ 手寫程式題，手寫題**每年約佔 40%~50%**（高點命題趨勢；108 年心得記載該年非選拉高到 50%）。準備時按 50 分的量練手寫，40 分是下限不是常數。

**送分區——掉了就沒了**

| 領域 | 內容 |
| --- | --- |
| 資料結構 | Tree（BST／Heap／走訪）、Sorting 全套比較、Graph（BFS/DFS、最短路、MST）、Stack/Queue/Array/Linked List、遞迴、複雜度分析 |
| 網路 | OSI 七層各層職責、TCP/IP、TCP vs UDP、三向交握、IP 與子網路計算、CSMA/CD vs CA、常見協定與 port |
| 作業系統 | Process vs Thread、排程演算法、記憶體管理與虛擬記憶體、死結、檔案系統、同步機制 |
| 資料庫 | ER Model、正規化 1NF–BCNF、SQL、ACID、索引 |
| 資安 | 對稱／非對稱加密、雜湊、數位簽章與憑證、PKI、防火牆與 DMZ、SQL Injection／XSS／DDoS |

**手寫題固定出在資料結構**。要練到能默寫的：Heap 的 insert/delete、Hash Table 含碰撞處理、BST 插入刪除、各排序、二元樹走訪，語言用 C++ 或 Java。作業系統近年比重在上升。

**趨勢區（逐年加重）**：AI/ML（監督與非監督、過擬合、損失函數、CNN/RNN/Transformer、LLM 與生成式 AI、bias 與 data imbalance）、雲端、IoT、區塊鏈、大數據、邊緣運算。

**基本區（低頻但簡單，不能掉）**：進制轉換、補數、浮點數表示、布林代數；OOP 四大特性、編譯 vs 直譯、傳值／傳址、指標。

**可斟酌放掉**：數位邏輯電路圖、OBST、紅黑樹、Thread Binary Tree、特殊矩陣、AOV/AOE、各種證明。
　※ 此取捨出自 Mavis 心得，但作者自己也寫「只要哪個地方放掉沒唸，考試就一定會考出來」。有時間仍建議掃過一遍。

#### 資訊管理導論與統計學（同一卷）

全手寫，統計約佔 50 分。**時間分配比會不會更致命**，務必拿整份考古題計時練。

**MIS 框架層**（要熟到能在考卷上直接畫出架構）
資訊系統分類 TPS/MIS/DSS/ESS、SDLC 與開發方法（瀑布／雛型／敏捷／DevOps／委外）、企業系統（ERP/CRM/SCM/KM/BI）、策略工具（Porter 五力、價值鏈九大活動、SWOT、BSC、CSF、TAM、創新擴散）。

**MIS 時事層**（每年必考，最能拉分）
生成式 AI／LLM 的企業應用與風險、數位轉型與 Enterprise Agility、ESG、資料治理與隱私（GDPR／個資法）、平台經濟與網路效應、資安治理與攻擊手段、Gartner 年度趨勢。

115 台大實際考過的方向：Community Detection、Enterprise Agility、Conversational AI、ESG——全是「給企業情境，結合理論提出解法」，不是名詞解釋。

**MIS 答題層**（這科考的是寫法，不是背誦量）
三件套＝理論框架＋分析＋案例。平常建一本案例庫（foodpanda→平台經濟、共享單車→共享經濟）考場直接調用。答案大量用列點與表格，少寫純文字長段落——Mavis 用這個寫法各校 MIS 分數都很平均。

**統計**
敘述統計 → 機率與分佈（常態／二項／Poisson）、貝氏 → 抽樣分佈與 CLT、信賴區間 → 假設檢定（z/t、型一型二錯誤、p-value）→ 卡方、ANOVA → 迴歸（簡單與多元、係數解釋、R²、F 檢定）。重心在檢定、ANOVA、迴歸、卡方。
　※ TKB 另提到會考「統計軟體操作概念（R、SPSS 常見指令解釋）」，此點僅單一來源，未在考古題上驗證。

#### 英文(B)

閱讀（科技與商業題材）、字彙、文法。權重只有 1，但用**英文科技新聞**當閱讀材料可一石二鳥，同時累積 MIS 時事素材。

#### 應試策略（已從考卷本身查證）

**選擇題倒扣**。107 年資訊科技概論卷頭明載：「選擇題（單選）24 題，每題 2.5 分，共 60 分。注意：答錯倒扣 1 分，扣至零分為止。（不答不倒扣）」高點命題趨勢與 108 年 PTT 心得亦分別佐證。因此「一律猜 E」是錯的策略，五選項的期望值是：

| 情況 | 期望值 |
| --- | --- |
| 完全亂猜 | 0.2×2.5 + 0.8×(−1) = **−0.3** |
| 刪掉 1 個（4 選 1） | 0.25×2.5 + 0.75×(−1) = **−0.125** |
| 刪掉 2 個（3 選 1） | 1/3×2.5 + 2/3×(−1) = **+0.17** |

至少要能刪掉兩個選項才值得猜，否則留空——不答不倒扣。

**作答語言：可用中文**。111 年資訊管理導論卷頭只寫「請於答案卷上依序作答，並註明作答的題號／試卷共四大題」，無語言規定；107 年資訊科技概論卷頭亦無。心得文中沒有任何一篇提到需用英文作答或因中文作答被扣分，補習班的申論架構與擬答也全是中文。專有名詞建議保留英文原文（Enterprise Agility、Community Detection、ESG 等）。
　※ 僅查證 111 MIS 與 107 IT 兩份卷頭，114／115 卷頭未取得（原始 PDF 於本環境無法下載）。實際仍以當年考卷第一頁為準。
　※ 命題語言另計：台大 MIS 常態為全英文命題，某年出現中文題目被考生形容為「中文沙必斯」。政大**面試**的英文關規定各年不一：112 心得記載「簡述內容」與「keyword」須用英文回答、後續提問改中文；114 共筆則記載教授明講 summarize「可用英文或中文」。以當年現場指示為準。

**115 卷面配分實測**：資訊管理導論與統計學該卷 Q1＋Q2 為 MIS 共 50 分，Q3(15%)＋Q4(20%)＋Q5(15%) 為統計共 50 分，驗證了「統計約佔 50 分」的說法。

#### 投入順序

資結與計概先動（份量最大、手寫題靠它）→ MIS 早點開始但可用零碎時間（吃飯配課）→ 統計中期集中刷題 → 10 月起全面轉考古題，MIS 開始練計時申論。

MIS 的時間分配是多數人的盲點：計概範圍嚇人，很容易把 MIS 壓到 1:20，但計概大家分數都接近，**MIS 才是拉開差距的地方**。上榜心得建議至少 1:9。

**教材**

- 台大于天立《計算機概論》開放式課程 —— 免費，無補習者的主要影音資源。

**讀法**：基本題與考古題考過的題目「絕對不能掉分」，這部分就已經贏過一半人；剩下的靠廣泛涉獵新科技名詞。

**範圍**

**教材**

- 案例來源：iThome、數位時代。看到案例就記進一本「案例筆記」，申論舉例時直接調用。

**讀法**：這科最能跟其他人拉開差距（計概大家分數接近）。答題要有架構＋理論＋案例三件套，只背定義寫不出好答案。有心得建議 MIS:計概 時間分配至少 1:9，別像多數人只給 1:20。

**注意**：台大是「資訊管理導論**與**統計學」同一卷，統計近年約佔 50 分（依 115 上榜心得），作答時間分配要先在考古題上練過。

### 3.3 統計學（僅台大，併入 MIS 卷）

| 主題 | 重點 |
| --- | --- |
| 敘述統計 | 平均/中位/眾數、變異數與標準差、偏態、盒鬚圖 |
| 機率 | 條件機率、貝氏定理、常態/二項/Poisson 分佈 |
| 抽樣與估計 | 抽樣分佈、中央極限定理、信賴區間 |
| 假設檢定 | z / t 檢定、型一型二錯誤、p-value |
| 變異數分析 | 單因子/雙因子 ANOVA、卡方檢定 |
| 迴歸 | 簡單與多元線性迴歸、係數解釋、R²、F 檢定 |

考試重點集中在**檢定、ANOVA、迴歸、卡方**。跨考生只要有修過基礎統計就不吃虧，關鍵在大量練題提升解題速度。教材以補習班統計學講義（大碩：張翔）或任一本基礎統計教科書即可。

## 四、二階口試

本節彙整十餘篇公開心得。**教授姓名、分關與題目均出自考生自述，非官方公告**，每年都會變；用途是理解「會被問到什麼層次」，不是猜題。推甄與考試入學的口試形式相同（同樣四關跑關），差別只在另一半分數是審查還是筆試，因此推甄心得同樣適用。

### 4.1 台大口試（佔總成績 40%）

#### 形式與計分

- **場地**：臺大管理學院一號館（某年在三樓玉山廳，內有四小間研討室）。
- **跑關制**：四人一組，先在預備區等候，再同時分別進入四間教室，起始關卡錯開（1→2→3→4、2→3→4→1、3→4→1→2、4→1→2→3），四關都會面到。**每間教室兩位教授**。
- **一關四到五分鐘**。有心得指出**推甄每關 4 分鐘、考試入學每關 5 分鐘**（同一人兩次都考過，說「考試入學大致跟推甄同模式，但每關多了一分鐘」）；114 推甄心得則記載「分成四關，共 16 分鐘」。**用投影螢幕嚴格計時、響鈴提醒，時間到會有人敲門叫你換關**，有考生形容「時間控制非常精準，完全沒有延後」。
- **關卡數並非一直是四關**：110 年有心得記載該年只有三關（中文基本問答、數學關、英文關）、全程約 15 分鐘，且設有獨立的英文關。111 年之後的心得則一致為四關。
- 有心得提到**不用帶備審資料進場**。
- 佔總成績 40%，**原始成績未達 70 分不予錄取**。進入資格為筆試總分前 48 名（115 學年度）。
- **計分公式**（115 上榜者自述）：

  ```
  總分 =［英文×1 + 資訊科技概論×2 + 資訊管理導論與統計學×2］× 0.6
      +［口試×5］× 0.4
  ```

  口試要**先乘以 5** 才與筆試同尺度——筆試三科加權後滿分 500，口試 100 分×5 也是 500。所以口試每 1 分，等值於筆試加權科目的 1 分。

- **時程**：3/6 公告名單 → 3/11 中午前上傳個人資料表與成績單 → 3/13 口試。**只有一週準備**。

- 五個人減肥前後體重的假設檢定題組：(1) 虛無假設與對立假設是什麼？(2) 如何求得 z-value 或 t-value？(3) 如何決定是否接受虛無假設？（同組有人被問 ANOVA 與 F-value）

#### 從十餘篇心得歸納的規律

1. **一關只有四分鐘**。答案要能在 30 秒內切入重點，鋪陳太久會被打斷。
2. **追問到底是設計出來的**。多位考生描述被問到答不出來為止——這不是失敗，是關卡的運作方式。
3. **抽題制**：桌上五到六張紙抽一張，有時學生抽、有時老師抽。同組每人題目不同。
4. **專題一定被挖到實作細節**。演算法怎麼運作、框架為什麼選它、格式一致性怎麼確保。當 free rider 會當場穿幫。
5. **數學關年年都有，而且要當場算**。筆試考完不能把統計和微積分丟掉。
6. **教授會測你有沒有查過系上老師**。講得出研究方向與名字是加分點。
7. **要聽同組其他人的回答**。教授會問「另一位同學的題目和你有關聯，你的看法呢」，沒認真聽會被扣分。
8. **答不出來時，講出推理過程仍能拿分**。有考生算錯但先解釋了運算邏輯，自評扣分沒那麼重。

#### 準備方式

- 專題要能講三層：做什麼、你負責哪一塊、遇到什麼問題怎麼解決。第三層最能加分——有考生講到解決過程時兩位教授都笑著點頭。
- 事先查系上教授的研究方向（可查碩博士論文系統），至少講得出名字與領域。
- 有考生的做法是**針對已知考官的專長準備**：孔令傑常擔任數學關考官且愛考作業研究，所以特地去看他的作業研究課程。分關人選每年會變，但這個思路可以借用。
- 統計與微積分維持手感到 3 月中。
- 準備尷尬題：為什麼沒推甄、有沒有補習、重榜會選哪裡、在校成績為什麼不好看、有沒有報其他系所。
- 自我介紹準備短版，並要有「根本沒機會講」的心理準備。
- 口試要訣是**不能愣住**，被問到不會的也要保持積極應對。模擬口試（補習班或找人陪練）多篇心得都說有用。
- 有考生的做法是開一個 Notion，把網路上找得到的考古題**按四關分類**歸檔，再逐關複習對應的專業科目。

**來自口試委員的視角**：台大資管系副教授孔令傑（口試數學關的常見考官）在一集談大學個人申請面試的 Podcast 中提到幾個原則——面試測的是抗壓性而非專業、中規中矩比標新立異安全、說實話最安全、最忌吹牛。該集談的是高中升大學，不是研究所口試，但出自實際擔任口試委員者之口，評分邏輯可以參考。

MIS 考 25 分還能正取，具體說明了口試 40% 的份量——筆試單科崩掉不等於出局，但口試崩掉就是直接出局。

#### 備取遞補時程

115 有考生記錄：**4/9 公告為台大備取 2，5/13 才收到備取通知**。備取生的等待期比多數人預期的長，這段時間仍需保留其他學校的報到選項。

### 4.2 政大面試（佔總成績 50%）

政大資管組是**團體面試**，有考生形容為「最硬的面試」。分三關：

**英文關**
面試前先被帶到教室閱讀一篇英文文章 10 分鐘（從 4 篇中抽籤決定），提供紙筆做筆記，**同組每人拿到的文章不同**，內容近似 paper 摘要。科技組的版本是三人一組、團體面試共 15～20 分鐘（各年不一），文章為一頁 A4 內含四段、抽籤擇一。有考生的做法是快速看兩遍後把整篇抄下來，邊抄邊抓 keywords——抄整篇的好處是在外面等下一關時還能繼續看。進場後系主任先自我介紹，再依面試編號依序提問：

- 這篇文章的主軸是什麼？（**英文回答**）
- 給我這篇文章的關鍵字（**英文回答**）
- 你認為文章寫的事件會如何影響社會？（中文回答）
- 另外一位同學的題目和你的有些關聯，你的看法呢？

**形式逐年在變**，準備時以近年為準：

| 年度 | 形式 |
| --- | --- |
| 110 | 五分鐘看短文（約六七行），五位面試官，開場先**英文自我介紹** |
| 111 | 四人一組、分兩關，五分鐘讀短文，**唸出短文第一句並翻譯**，再依內容延伸提問 |
| 112 | 三人團體面試 20 分鐘，面試前 10 分鐘在小房間抽讀 |
| 113 | 文章很短（約 1/4~1/3 頁 A4），10 分鐘看＋筆記，改為**英文總結＋三個關鍵字** |
| 114 | 一頁 A4 四段抽一段，三人一組 20 分鐘 |
| 115 | 團體面試約 15 分鐘 |

早年要「唸出來並翻譯」，近年已改成「summarize＋keywords」，且不再要求英文自我介紹。曾出現的題材：TSMC 在亞利桑那設 AI 晶片廠、相關廠房也有意願外移，這是否會使台灣矽盾優勢消失？歐盟對蘋果壟斷音樂串流開罰。

**程式關**
一共五題，**搶答制**，有想法就舉手。問這段程式在做什麼、要改寫成其他語言會用什麼邏輯、時間複雜度是多少。題目紙上印六題。曾出：遞迴的 Python 把奇數變成負值；延伸題；最後一題問「如果這題要用 LLM 撰寫，你會怎麼下 Prompt，把我們當成機器說明你的提示字」——教授說講得出來就當場錄取。**「如何對 ChatGPT 下 prompt 寫出這段程式」連續多年出現**，是政大程式關的固定考法之一。

**備審／生涯關**
教授會用筆電當場翻你的備審，主要針對研究計畫提問，目的是確認你對自己寫的內容夠不夠了解。曾被追問「為什麼要自己訓練模型，而不是用別人 train 好的、像 ChatGPT？」有考生因為沒仔細聽其他人的回答，被教授問是不是沒認真聽而扣分。

**兩個作答提醒**：政大資結只有 4 面 A4 可寫，sorting 的 code 要記熟並計時練習，很多人寫不完；另有考生因為考古題那題「要全對才給分」、自己把 8 寫成 0 而失分，提早交卷前務必逐字核對。

**注意**：政大計概的手寫程式題，評分不只看跑不跑得出正確結果。有考生自估 80 分以上、實際開 IDE 執行也正確，分數卻遠低於預期，推測是寫法不合閱卷者的預期。作答時把思路與註解寫清楚。

早年版本的政大口試則是：教授指定每人唸一段英文句子並翻譯、問其中單字意思 → 兩位教授針對研究計畫提問 → 一位教授出程式題（曾用 Scala，教授先講解再搶答）→ 一位教授問 MIS（例：跨界結合對台灣中小企業有什麼挑戰）。
