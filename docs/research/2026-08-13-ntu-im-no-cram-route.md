# 台大資管所：不補習路線與推薦教材

查驗日期：2026-08-13
適用年度：**116 學年度（2027 年 2 月筆試）**。116 簡章預計 2026 年 10 月底公告，考科與計分屆時要重新核對。考科結構沿用 115（見 `2026-08-11-ntu-nccu-mis-exam-prep.md` 第一節）。

**取材範圍**：`public/data/resources.json` 內全部 151 筆台大資管相關資源，逐筆掃過並挑出與教材、補習相關的段落；其中 15 篇本次讀過原文（第九節標示）。

**為什麼有補習者的心得同樣是主要依據**：他們的文章裡寫著補習班實際教了什麼、哪幾科教得不夠、題庫班在做什麼、學費多少。**對自學者而言，那是一份規格書**——你要自己補的就是那些內容，而他們親口說「補習班這裡不夠」的地方，你本來就不用羨慕。第五節專門處理這件事。

分界不在補不補，而在**能不能自己決定範圍、自己排進度、自己拿到解答與回饋**——補習班賣的就是這三樣。

## 三、自學真正的缺口：解答與回饋，不是教材

教材網路上到處都有，**台大圖書館只給題目不給解答**（`res-official-ntu-lib`）。庫內能找到的解答來源：

| 來源 | 說明 |
| --- | --- |
| `res-solutions-im-108` | 張逸老師版 **108 年五校計概試題＋解答**，逐題標註題型。少數公開的解答來源 |
| 蝦皮那套計概筆記 | `res-dcard-im-112-ntu-nocram`：「那本筆記是可以信任的，練習題都來自考古，總共似乎只有兩三個錯誤」 |
| LLM 產擬答 | 見下方 |
| 讀書會 | `res-dcard-im-113-admitted` 專門寫了一節：找**少少幾個人**、心態是戰友不是對手；他吐槽加過太多讀書會「進去後都沒有人要講話，每個都只想當伸手牌」 |
| 只報單科題庫班 | `res-hackmd-im-108-oral`：「動機單純只是想要有答案……其實蠻浪費錢的」（1 月才報，價格與 9 月相同） |
| 成大考古題 | `res-official-ncku-im`：題型與台大／政大高度相似，可當額外題庫 |

**LLM 是自學者這兩年新增的槓桿，但要照規矩用。** 最完整的用法出自 `res-dcard-im-115-tech`（有補習者），原則是「**大量使用生成式 AI，極少完全相信它**」：他提醒 LLM 是機率模型、會產生幻覺，但「對於網路上已經有大量資料的領域（例如資管所的計概與資結考科），它的回應可能（甚至通常）**會比補習班老師給的更好**」。他公開的考古題 prompt 大意是：附上該年考古題 PDF，要求逐題詳解、**補充每個錯誤選項錯在哪**、再結合當前科技趨勢與教授可能的考點做延伸補充。另一種用法是把自己理解的觀念用自己的話講一遍請它糾正（例如「把我理解的 ARP／RARP 步驟順一遍，問我觀念中是否有錯」）。

`res-dcard-im-114-nocram-oral` 的做法一致：考古題截圖丟 GPT／Gemini／Claude 要擬答，**自己再重寫一次**；`res-dcard-im-113-admitted` 也用 ChatGPT 整理沒看過的概念，但強調「還是需要自己去查證」。

**解答地雷（三個獨立來源，含兩位有補習者）**：

1. `res-dcard-im-112-ntu-nocram`：「**請千萬不要買某補習班網站上賣的考古題解答**！裡面錯誤百出，大概每五題就有兩題是錯的。」
2. `res-dcard-im-114-cross`（有補習）：計概題庫班「我上到後面發現**有很多題目老師講的答案都是錯的**……我擔心自己越看反而學到更多錯的知識」，資料庫／網路／AI 題庫班同樣「一樣也有很多題目講的是錯的」，導致她每題都要自己查一次，「整個讀書效率慢了至少 5 倍」。
3. `res-dcard-im-115-tech`（有補習）：「有老師解考古題，**很誇張的五題可以錯兩題**，不知道為什麼能那麼有自信。」

## 四、MIS：庫內最分歧的一科，四票說不必重壓

**A 派：自學難度最高**

- `res-dcard-im-112-ntu-nocram`（無補習正取台大）：「我讀了兩輪，成績還是慘不忍睹……可以找有補習的同學組讀書會，刺探敵情。」
- `res-hackmd-im-112-nocram-ordinary`：「這科很難自學，雖然是最容易入門，但也是很難拿高分的科目。並且更多的是**不知道怎麼進步**。」（他因此只補了 MIS）

**B 派：不必重壓，甚至不必補**

- `res-dcard-im-113-admitted`（全補習、四校全正取）：「補習班老師的教法**只適合想考中字輩的學生**……老師以管理學的方式教 MIS，但我更喜歡以技術的角度解題。」他後期完全不管老師框架，改用**解 case 的流程**作答，並指出「細細研究考古題後會發現**台政的考題完全不考傳統 MIS 的東西**」。
- `res-dcard-im-114-cross`（全補習、正取台大）：「很多我聽過的學長姐都說，他們 MIS 根本沒什麼準備，但成績出來一樣沒有比補 MIS 的人差、甚至更好……這真的很看**個人的邏輯答辯能力**，只要敘述有條理、邏輯清楚分數就不會低；反之讀再多理論定義、背再多構面，分數都起不來。**考試分數能拉開差距的還是靠計概**，不用花太多時間鑽研 MIS。」
- `res-dcard-im-115-tech`（全補習、四校全正取，科技組）：「**MIS 正課都不用上**，多看一些科技新聞、分析，瞭解最新趨勢我認為更實際……臺大 MIS 申論題真的是**你能寫出你自己的邏輯比較重要**，而不是背了多少 MIS 名詞。」他的具體戰術是準備幾個萬用分析框架，考場上把回答引導到熟悉的地方（例：看到「為何 IT 投資失敗」就寫 IT 策略未與商業策略校準、互補性資產不足、組織抗拒等）。
- `res-medium-im-111-zheng`：刻意不寫補習班的起承轉合，改用精煉寫法，理由是考場要顧的是**精準度**不是筆速。

**合起來的結論**：A 派說的是「沒有回饋就不知道怎麼進步」，B 派說的是「補習班的模板對台大不一定加分、且這科拉不開差距」。兩者不衝突——**要練的是產出與回饋機制，不是模板；而且時間不該給到超過計概。** 庫內可抄的練法：

| 練法 | 出處 |
| --- | --- |
| 每天寫一篇時事申論、考前累積 30–40 篇並固定回頭複習，用電腦打字以專注在思考 | `res-medium-im-111-zheng` |
| 三遍讀法：①瀏覽 ②把**考古考過的知識點註記在講義上** ③做心智圖只寫關鍵字，但看到關鍵字要能說出 5W1H | `res-hackmd-im-108-oral` |
| 案例庫：背熟理論後每週做 2–3 次案例分析並找人討論，持續 2–3 個月；遇到不會的題目讀一本專書補（平台經濟題→《平台革命》） | `res-tkb-nccu-113-case` |
| 準備幾個萬用分析框架，把題目引導回熟悉的框架 | `res-dcard-im-115-tech` |
| 三件套＝理論框架＋分析＋案例，大量用列點與表格 | `res-blog-im-mavis` |

　※ 分數期望值先校準：`res-ptt-im-108-ntu` 台大 MIS **25 分**仍正取（口試 87.14）；`res-dcard-im-113-admitted` 管理概論 **40 分**、四校全正取；`res-dcard-im-114-nocram-oral`：「有些系所的考科拿個 30 分可能就已經是 PR 80 了（對，我就是在說台大的 MIS）」。**這科不是拿高分的科目，是不能崩的科目。**

### 5.4 題庫班到底在做什麼（決定要不要只補這一段）

`res-dcard-im-114-cross` 逐科拆得最細：資結題庫班「把觀念統整分類，依分類帶你複習＋密集做題，對理清觀念蠻有幫助」；計概題庫班「一直在解各校考古」（但答案錯很多）；資料庫／網路／AI 題庫班「統整這幾個領域的考古，因為近幾年這些領域都會考很多新名詞」；MIS 題庫班則是密集練申論＋讀書會，她自評「**我在題庫班是真的進步了很多**，不過如果正課就已經跟上的人可以考慮要不要上」。

其他人的判斷：`res-dcard-im-113-admitted`「我有上，但主要是**花錢買心安**……管理組的資結題庫班可以不用上」；`res-hackmd-im-108-oral` 只為了買答案而報，自評浪費。

## 八、無補習者專屬的口試問題

台大口試佔總成績 40%、四關各四分鐘（完整題庫見 `2026-08-11-ntu-nccu-mis-exam-prep.md` 第四節）。與自學路線直接相關的：

1. **「你是不是沒補習？」是真的會問**，而且**有補習的人也會被問**：`res-dcard-im-112-ntu-nocram`（無補習）生涯關被問「你是不是沒補習？還有考上其他什麼學校？」；`res-dcard-im-114-cross`（有補習）生涯關被問「**有沒有補習？哪一家？**」。兩邊都要準備一個不心虛的答法。
2. **跨考＋自學＝修課紀錄會被追**。`res-dcard-im-114-nocram-oral` 生涯關原題是「相關修課紀錄太少要怎麼處理、為什麼想跨領域來資管」；`res-dcard-im-112-ntu-nocram`：「跨考生如果沒有正式上過基礎課程（程設、資結），找教授時會比別人辛苦很多。」
3. **自學者的補救牌是專案**。`res-dcard-im-113-admitted`：「網路上買一些 ML 的課做小專案……台大口試會問到研究計畫，你有專案經驗可以從裡面發想研究興趣。」他生涯關就用「Airflow+ML 自動化預測專案」順順講完四分鐘。
4. **一階上了才開始準備數學關，來得及但很硬**。`res-dcard-im-114-cross`：「上了一階之後開始狂讀猛讀作業研究、統計、微積分、線性代數……我準備的方式是去看網路上的**各種開放式課程**」——結果仍抽到沒準備到的部分（四題只答出兩題）卻仍正取。

114 年兩份四關實錄可交叉看：無補習者（`res-dcard-im-114-nocram-oral`）數學關考機率、決策樹、期望值、貝氏定理；有補習者（`res-dcard-im-114-cross`）同年數學關考微積分與機率，技術關則因自己提到 LLM 而被追問 Transformer 與 LSTM 的差別、卷積層池化層在幹嘛。**兩人的技術關題目都是自己講出來的名詞被追問的**——講出口的每個詞都要能守住。
