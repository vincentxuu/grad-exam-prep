# Learning How to Learn 六個月備考執行規劃

## 1. 目標與適用範圍

本規劃把《Learning How to Learn》的核心方法套用到本站「台大資管所六個月不補習版」，對應 8 月起跑、隔年 2 月筆試。科目進度仍依現有計畫進行，但完成標準由「看完教材」改成「能在沒有提示時正確提取並應用」。

最終成果不是完成多少影片或筆記，而是能做到：

1. 不看資料解釋核心概念、比較相近觀念。
2. 在限定時間內辨認考點並完成題目。
3. 默寫常考資料結構與演算法程式碼。
4. 用錯題指出自己的錯誤模型，並在間隔後重做成功。
5. 將英文、MIS 案例與技術觀念帶進實際考題情境。

## 2. 六項執行原則

### 2.1 主動回想優先

每次學習前後都必須有一次不看資料的輸出。只閱讀、畫線、抄筆記，不算完成學習。

可接受的輸出包括：

- 白紙寫出概念架構。
- 口頭說明「是什麼、為何需要、如何運作」。
- 默寫程式碼或公式。
- 回答自製問題或考古題。
- 比較兩個容易混淆的概念。

### 2.2 間隔複習

每個新知識至少安排六次接觸：

| 時點 | 動作 |
| --- | --- |
| 學習當下 | 關書重建與立即自測 |
| 隔天 | 開始新進度前回想 |
| 第 3 天 | 閃卡、短題或默寫 |
| 第 7 天 | 與其他章節混合測驗 |
| 第 14 天 | 放進考古題或申論情境 |
| 第 30 天 | 只依錯題與弱點抽查 |

零碎知識交給閃卡 SRS；大型概念、計算題與程式題放進週複習和考古題。

### 2.3 專注與發散交替

一個學習區塊以 45–60 分鐘為上限，完成後離開螢幕 5–15 分鐘。卡題超過 20 分鐘時，先記下卡點、切換科目或休息，之後再回來。

休息不是繼續滑短影音；可散步、洗澡、做家事、運動或小睡，讓大腦有真正的發散時間。

### 2.4 建立知識組塊

每個重要概念都用相同框架整理：

1. 它是什麼？
2. 它解決什麼問題？
3. 它如何運作？
4. 它和什麼容易混淆？
5. 有什麼限制或代價？
6. 考題可能怎麼問？

如果只能背出定義，卻不能回答第 2、4、6 題，代表組塊尚未形成。

### 2.5 以測驗揭露學習錯覺

完成教材後，必須在不看資料的情況下通過至少一種測驗：

- 概念題正確率達 80%。
- 能在白紙重建該節架構。
- 能在限定時間內完成程式或計算。
- 能把概念套入一題考古題。

第一次測驗失敗是正常資料，不應立刻重看整章；先定位缺口，再只補相關段落。

### 2.6 混合練習

學習初期可依章節練習；從每週複習起，必須混合不同章節，訓練「判斷該用什麼方法」，而不只是重複同一題型。

## 3. 每日執行模板

以下以每日約 3.5–4.5 小時的有效學習時間設計；時間不足時保留順序、縮短長度，不取消回想與自測。

### 區塊 A：昨日提取，20–30 分鐘

1. 不看筆記列出昨天的三至五個核心概念。
2. 回答昨天留下的閉卷問題。
3. 標記為「穩定／模糊／忘記」。
4. 只針對模糊與忘記的部分回查。

### 區塊 B：主科新進度，90 分鐘

1. 5 分鐘：先寫下對主題的既有理解。
2. 45–55 分鐘：觀看課程或閱讀教材。
3. 10 分鐘：離開螢幕休息。
4. 15 分鐘：關書重建。
5. 10–15 分鐘：做題或建立三個閉卷問題。

### 區塊 C：輸出練習，45–60 分鐘

依科目選擇：

- 計概／資結：做題、畫資料結構、默寫程式。
- 統計：不看解答完成計算並寫出選擇公式的理由。
- MIS：用「理論、案例、影響、建議」四格寫短答。
- 英文：讀一段文章、關閉原文後口述摘要，再整理生字。

### 區塊 D：閃卡，20–30 分鐘

1. 到期卡優先，全部完成後才看新卡。
2. 每日新卡上限 20 張，不要求每天吃滿。
3. 到期卡超過 60 張或「不會」超過 30% 時，新卡降至 5–10 張。
4. 連續三天仍清不完到期卡時，暫停新卡直到積欠歸零。
5. 評分依能否在提示前完整回答，不因「看到答案覺得熟」而算會。

### 區塊 E：收尾，10 分鐘

記錄：

- 今天真正會了什麼？
- 哪個錯誤最值得留下？
- 明天第一個要回想的問題是什麼？
- 是否需要調整新卡量或教材進度？

## 4. 每週節奏

| 日程 | 主要任務 |
| --- | --- |
| 週一至週四 | 新進度、關書輸出、章節題 |
| 週五 | 混合題、程式默寫或統計計算 |
| 週六 | 小型計時測驗、考古題片段、完整訂正 |
| 週日 | 不開大量新進度；週回想、錯題重測、下週調整 |

### 每週檢查表

- 本週安排的教材是否完成，不以播放完畢為準？
- 上週錯題不看答案重做的成功率是否達 80%？
- 能否白紙重建本週最重要的三個概念？
- 是否有某科連續兩週完全沒有輸出練習？
- 閃卡到期量是否可在 30 分鐘內處理？
- 實際有效學習時間與預估相差多少？

若新進度完成率高但重測成功率低，應減少新進度；若重測穩定且負荷偏低，再增加題量，而不是增加筆記量。

## 5. 各科學習方法

### 5.1 資訊科技概論

每一主題建立一張「問題—機制—取捨」卡，例如：

- 為什麼需要 virtual memory？
- page fault 發生時誰做什麼？
- paging 解決什麼，又帶來什麼成本？
- paging 與 segmentation 如何區分？

完成標準：能用自己的話解釋，並在選擇題中辨認錯誤敘述。

### 5.2 資料結構與 C++

採三層輸出：

1. 說出資料結構的不變條件與操作複雜度。
2. 在紙上畫出操作前後狀態。
3. 不看講義默寫核心程式碼。

程式默寫完成後必須自行 trace 一組輸入；只背出外觀但無法追蹤狀態，不算通過。

### 5.3 作業系統、網路與資料庫

避免只背名詞，使用因果鏈：

```text
問題 → 機制 → 執行流程 → 成本／失敗模式 → 相近機制比較
```

每週至少挑一個主題向「完全沒學過的人」口頭解釋三分鐘，錄音後檢查是否跳步或只堆疊術語。

### 5.4 統計

每題訂正要分清：

- 看不懂題意。
- 選錯模型或公式。
- 計算錯誤。
- 解讀結論錯誤。

重做時換數字或混入其他題型，避免只記住原題步驟。每週至少一次 30–45 分鐘計時混合題。

### 5.5 MIS

每個理論建立：定義、適用情境、真實案例、限制、可能申論問法。每週累積一個案例，但必須能套用至少兩個理論，避免只收藏新聞。

申論採四層：

1. 先定義與表態。
2. 分析機制或利害關係人。
3. 放入具體案例。
4. 說明風險、限制與建議。

### 5.6 英文與單字

每日文章不追求逐字翻譯：

1. 先讀全文抓主旨。
2. 關閉原文後用中文或英文說出摘要。
3. 只查影響理解或考試常見的字。
4. 生字卡包含原句或個人熟悉情境的例句。
5. 每週用考古題檢查字彙是否能在上下文辨認。

## 6. 錯題本規格

每筆錯題只保留可驅動下次判斷的資訊：

| 欄位 | 內容 |
| --- | --- |
| 題目／來源 | 年份、題號或教材章節 |
| 錯誤類型 | 知識缺口／概念混淆／計算／審題／時間 |
| 原本想法 | 當時為何會選錯或寫錯 |
| 正確規則 | 一至三句可操作的判斷規則 |
| 觸發線索 | 下次看到什麼字或條件要想到它 |
| 重測日期 | 第 1、3、7、14 天；答對兩次才結案 |

禁止把整份詳解抄進錯題本。若一筆筆記無法在一分鐘內複習，應重新濃縮。

## 7. 閃卡製作規則

### 應該製卡

- 高頻定義、比較與條件。
- 自己在考題中犯過的錯。
- 程式碼的關鍵一步或不變條件。
- 公式的使用條件，不只是公式外觀。
- 英文生字、搭配詞與情境例句。

### 不應該製卡

- 整頁教材或過長申論答案。
- 不理解內容時直接複製的句子。
- 可由理解立即推出、且從未出錯的細節。
- 一張卡同時詢問多個互不相干的答案。

### 卡片品質檢查

- 問題是否只有一個清楚的測試目標？
- 答案是否能在 30–60 秒內完成？
- 是否測提取，而非辨認？
- 若連錯三次，是否應拆卡或回教材補概念？

## 8. 六個月階段規劃

### 第 1 個月：建立地圖與學習系統

目標：知道台大考什麼，完成計概與 OS 主幹，建立可持續的回想與複習習慣。

新增啟動任務：

1. 用 2–3 天了解主動回想、間隔複習、知識組塊與學習錯覺。
2. 掃近三年考古，只分類主題與熟悉度，不急著完整作答。
3. 建立錯題本模板與每週回顧頁。
4. 連續七天跑每日模板，再依實際可用時間修正。

既有任務的新完成標準：

- 于天立 21 講：每講留下三個閉卷問題，隔天答對至少 80%。
- Brookshear 前四章：每章一張白紙架構與五題自測。
- OS 前半：能解釋 process、scheduling、memory、paging 的因果鏈。
- 比較表：不看表也能講出差異與適用情境。

### 第 2 個月：程式、資料結構起步與網路

目標：把知識轉成可默寫、可追蹤的程序技能。

- 每天默寫一段 stack、queue、sorting 或 tree 程式。
- 每次默寫後 trace 一組輸入並標註複雜度。
- 網路每章建立一張分層圖與協定比較。
- 英文科技文章維持每日輸入，但每週至少一次閉卷摘要。
- 週六加入 30–45 分鐘計概混合題。

### 第 3 個月：資結主攻與 MIS 第一輪

目標：完成資結核心組塊，開始跨科應用，而不是只讀完教材。

- Heap、Hash、Graph、Sorting 各通過一次紙筆默寫。
- 每讀完一章立即做題；未達 80% 不急著擴張新進度。
- MIS 每章留下三個可申論問題，不抄長篇摘要。
- 每個 MIS 案例至少對應兩個理論。
- AI、資料庫等新主題用比較卡和考古題驗證。

### 第 4 個月：統計與整份計時考古

目標：從章節學習切換到混合判斷與時間管理。

- 每週至少一份完整、計時考古題。
- 作答後先估計錯誤類型，再看詳解。
- 每份考卷在 48 小時內完成訂正。
- 七天後不看解答重做錯題。
- MIS 每週一篇計時短申論。

### 第 5 個月：弱點回填

目標：以錯題證據決定進度，停止從頭重讀。

- 依錯題數、重測成功率與耗時排弱點優先序。
- 每週只選兩個主要弱點集中處理。
- 回教材只讀能修補該缺口的段落。
- 網路與資料庫練習「為何需要此機制」。
- 英文與 MIS 改成計時產出。

### 第 6 個月：考試提取與穩定性

目標：讓已學內容在壓力與時間限制下穩定輸出。

- 考古題以整份計時與重寫為主，不再追逐大量新教材。
- 每天維持一段程式碼與少量統計題手感。
- 每週至少一次模擬正式考試時段。
- 檢討時間配置、抄寫錯誤與猜題策略。
- 考前一週只看錯題、重點卡與既有筆記，不開新進度。

## 9. 進度衡量方式

不要只使用「完成任務數」。每週記錄六個指標：

| 指標 | 建議目標 |
| --- | --- |
| 隔日閉卷回想正確率 | 80% 以上 |
| 七日錯題重測成功率 | 80% 以上 |
| 閃卡到期完成率 | 每日 100% 或三日內清零 |
| 新卡再次答錯率 | 30% 以下；更高就減量或拆卡 |
| 每週輸出次數 | 每主科至少 2 次 |
| 計時題完成度 | 每月逐步提高，不只看分數 |

單週分數下降不等於退步；若題目更混合、提示更少，下降可能代表測驗變得更真實。重點是錯題能否在下次間隔重測中修正。

## 10. 落後與過載處理

### 到期卡太多

1. 先停新卡三天。
2. 刪除低價值或重複卡。
3. 將過大的卡拆小。
4. 連錯卡回教材理解，不靠無限重刷硬記。

### 教材進度落後

1. 不犧牲睡眠與回想時間追影片。
2. 依近年考古頻率砍低價值章節。
3. 保留核心章節的輸出與做題。
4. 將「完整看完」改成「針對弱點查讀」。

### 很多內容都不會

1. 每次只選一個最小缺口。
2. 回到前置概念，而不是重看整門課。
3. 學完立刻做一題最簡單的成功測試。
4. 隔天再測；能連續兩次獨立答對才繼續擴張。

### 精神狀態差

執行最低版本：10 分鐘回想、10 分鐘到期閃卡、20 分鐘單一小節。保持學習鏈比勉強完成一整天排程重要。

## 11. 前兩週啟動安排

### 第 1 週：建立方法

- 第 1 天：掃一份近期考卷，建立「會／模糊／不會」主題表。
- 第 2 天：建立錯題本格式，試做一次關書回想。
- 第 3 天：開始于天立計概，實驗一個完整學習循環。
- 第 4 天：隔日回想並調整問題大小。
- 第 5 天：加入 OS；練習三分鐘口頭解釋。
- 第 6 天：完成第一次混合小測。
- 第 7 天：只複習、重測與調整下週負荷。

### 第 2 週：建立穩定節奏

- 每天先做隔日回想，再開新教材。
- 主科維持一至兩個學習區塊，不同時開太多資源。
- 閃卡到期優先，新卡依錯誤率控制在 5–20 張。
- 週六做第一次 45 分鐘考古題片段。
- 週日檢查重測率、到期卡量與實際有效時數。

兩週後若隔日回想未達 70%，先減少 20–30% 新進度；若穩定超過 85% 且每日負荷可控，才逐步增加題量。

## 12. 每日最小檢核

每天結束前只需回答五題：

1. 今天有沒有至少一次關書輸出？
2. 今天有沒有處理到期複習？
3. 今天最重要的錯誤是什麼？
4. 明天第一個回想問題是什麼？
5. 今天的負荷能否連續維持一週？

若五題中連續三天有兩題以上回答「沒有」，應先降低新進度，而不是延長讀書時間。
