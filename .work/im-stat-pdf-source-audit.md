# 台大資管所統計學 PDF 與來源稽核

稽核日期：2026-08-16
權威來源：台大圖書館碩士班考古題索引、repo 內台大圖書館原始 PDF

## 結論

- **106–113 學年度確認沒有獨立的統計學筆試科目／題卷**，不是「統計卷尚未取得」。台大圖書館官方索引在每一年度的「資訊管理學研究所」名下只列英文(B)、資訊科技概論、資訊管理導論三科；同期間八份資訊管理導論 PDF 也各自構成完整 100 分考卷。
- **114 學年度開始在資訊管理導論卷內實際出現統計題**：Q1–Q3 是 MIS 共 65 分，Q4–Q5 是統計共 35 分。官方索引當年仍把科目名稱列為「資訊管理導論」。
- **115 學年度官方科名正式改為「資訊管理導論與統計學」**：Q1–Q2 是 MIS 共 50 分，Q3–Q5 是統計共 50 分。
- 現有五題統計題中，**三題題文正確、兩題重大誤抄**：114 Q5 的估計量分母錯誤；115 Q3 的 PMF 公式被改成另一個函數。兩題的現有答案也因此錯誤。
- 四個明列子題的統計題中，114 Q4 與 115 Q4 的 `subQuestions` metadata 為空；修復 manifest 已補齊，因此 114 Q4、Q5 與 115 Q3、Q4 都會保留正確子題結構。
- 五題都是開放式計算／證明題；`answers.json` 目前填入 `A` 或 `C` 都不是卷面選項，應統一為 `N/A`。
- 拆分 MIS／統計後仍殘留 **37 個已不存在於 questions.json 的 `im-stat` qfile**；它們是 106–113 全部 32 題、114 Q1–Q3、115 Q1–Q2 的 MIS 複本，應刪除。
- `q-pp-im-stat-114-4` 的圖片映射錯指 PDF 第 3 頁（Q5），正確回歸表在第 2 頁；`paper-images.json` 所列的五個 `pp-im-stat-*` 圖片檔目前也都不存在，需從兩份 PDF 重新渲染。

## 稽核方法

1. 完整閱讀 PDF skill，依規則以 Poppler `pdftoppm -r 220 -png` 渲染 114 的 3 頁與 115 的 2 頁。
2. 逐頁以原始解析度視覺檢查題文、公式、表格、子題與配分；文字擷取僅作輔助，未用 OCR 取代視覺判讀。
3. 比對 `public/data/questions.json`、`public/data/answers.json`、`public/data/question-images.json`、`public/data/paper-images.json` 及 `public/data/qfiles/`。
4. 使用 AGENTS.md 指定的 `stealth_fetch` 查詢台大圖書館官方索引，逐年過濾「資訊管理學研究所」。
5. 檢查 106–113 資訊管理導論卷面；八年題目配分各自加總 100 分。

115 Q3 卷面公式是：

`f(X₁,X₂) = (|X₁| + |X₂| + |X₁+X₂|) / c`

（指定支撐集合以外為 0）。現有題庫卻改成 `c × numerator / [(1+|X₁|)(1+|X₂|)(1+|X₁+X₂|)]`，卷面完全沒有這三個分母因子。正確結果：

- `c = 12`。
- 聯合 PMF：`(-1,-1):1/6`、`(0,-2):1/6`、`(0,0):0`、`(1,-1):1/6`、`(1,1):1/6`、`(2,0):1/3`。
- `Y₁` 邊際 PMF：`-1:1/6`、`0:1/6`、`1:1/3`、`2:1/3`。

115 統計部分合計：15 + 20 + 15 = **50 分**。
