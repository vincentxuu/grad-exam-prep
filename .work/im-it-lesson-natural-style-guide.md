# IM-IT 課程自然教學風格

## 原則

1. 先講人話，再補術語：中文句子先成立，英文術語只在第一次出現時用括號補充。
2. 一段只處理一個判斷：避免連續堆疊四個以上名詞與定義。
3. 從考題線索帶觀念：優先使用「看到什麼」「先判斷什麼」「為什麼」的順序。
4. 例題要像老師帶解：steps 寫判斷過程，不寫報告式摘要。
5. 審核資訊只在頁面固定揭露：summary 不重複塞入 refs、eligible、technical review 等內部語言。

## 文案檢查

- 標題可用問題或情境，不用連續羅列三個以上術語。
- Section body 以 2–4 個短句為主。
- 每節 bullets 以 2–3 點為優先；只有必要時才到 4 點。
- 避免中文句中反覆混用 input、output、target、refs、implementation 等字。
- Cards 的 front 應能讓學生用一句話作答。
- Pitfalls 寫「容易怎麼選錯」，不要寫成規格文件。

## UI 用語

- 「完成後你會」→「先抓住這幾件事」
- 「帶你解題」→「一起拆題目」
- 「答案」→「所以答案是」
- 「常見陷阱」→「這裡最容易選錯」
- 「概念卡自我檢查」→「換你快速判斷」
- 「接著用考古題驗證」→「最後用考古題驗證」
