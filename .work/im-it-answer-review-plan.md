# IM-IT 選擇題答案覆核計畫

## 目標

把 246 題選擇題從 `legacy_import / low` 逐題提升為可重現的單人技術覆核結果；
只讓答案唯一、解析可重現且題目完整者取得練習與自動判分資格。

## 信心規則

- `medium`：單一 reviewer 可由題目、選項與完整技術推導得到唯一答案。
- `low`：推導或依據不完整，仍需補資料。
- `disputed`：多解、無正確選項、題意歧義或 reviewer 與現有答案衝突。
- 本階段沒有官方 key，也尚未雙人獨立覆核，因此不得標 `high`。

## 發布規則

- `confirmed / medium`：可進主題練習與自動判分候選。
- `corrected / medium`：先修正答案與解析，再進第二人覆核；本輪不直接發布。
- `disputed`：退出自動判分，題庫頁顯示爭議狀態。
- `insufficient / low`：保留瀏覽，等待補來源或重新推導。
- 14 題程式／開放題不在本輪，仍使用 self-review gate。
