# IM-IT 生活情境整合設計

## Subject / audience / job

- 主題：研究所資管考試的資訊科技概論
- 使用者：知道一些名詞、但尚未建立可用心智模型的考生
- 頁面唯一任務：把一個抽象判斷轉成能理解、能回想、能用於考題的模型

## Visual system

- Palette：沿用網站 foreground/background；情境使用淡藍 `sky`，翻譯對照使用低彩度 `muted`，邊界使用淡琥珀 `amber`，不另造全站品牌色。
- Type：沿用全站中文字體；情境問題用較大 medium，技術詞使用 utility-style 小標籤與等寬感 tabular layout。
- Layout：單欄閱讀；情境 → 對照翻譯帶 → 邊界 → 考題線索，手機版保持同一閱讀順序。
- Signature：生活語言與電腦語言的逐列翻譯帶；它是內容關係，不是裝飾。

## Wireframe

```text
┌ 先想像這個場景 ─────────────────┐
│ 生活問題                           │
│ 先別急著看答案：你會怎麼判斷？     │
└───────────────────────────────────┘

  把故事換成電腦語言
  生活中的角色       →       技術概念
  共享廚房的廚師     →       threads
  各自的小抄         →       stack / PC

  比喻到這裡為止：...

  題目出現這些字，先想到：...
```

## Self critique

- 放棄額外插圖與動畫：目前核心問題是文字生硬，圖像會讓原型難以判斷究竟是內容改善還是視覺新鮮感。
- 不使用多色卡片矩陣：會再次產生模板感，也切碎連續推理。
- 保留一個主要場景並立即正式化；不把整堂課改寫成長故事。
