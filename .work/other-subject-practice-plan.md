## 產品原則

1. 題庫是評量層，不是教學內容層；每科先建立主題講義、例題與常見錯誤。
2. 每張卡、例題與解答都要有 `topicId`、來源與審核狀態。
3. 練習入口由內容覆蓋率決定；內容不足時顯示「建置中／只開放題庫」，不能做空入口。
4. 完整年度卷通過題目、圖片、答案檢查後，才能進模擬考。
5. 不同科共用流程骨架，但練習動作依科目調整。

## 已確認的第零階段決策

- 現有 160 張非英文閃卡（計概 60、MIS 50、統計 50）正在從 production 隔離到 `archive/flashcards/im-nonenglish-legacy.json`。
- 不直接把 legacy 卡改 topicId 後重新上線；無來源問題仍然存在，改 ID 不能讓內容變可信。
- archive 只作為候選素材。後續每張卡必須對照 concept master、教材或真題，通過審核後重新生成。
- 隔離期間保留舊卡 ID 供 SRS 歷史識別，但 API 不再把卡片提供給新練習。
- 這批隔離是既有並行工作，本規劃不修改、不提交或覆蓋其檔案。

## 建議內容模型

每個主題建立一個可驗證的學習單元：

- 核心概念與學習目標
- 公式／框架／名詞清單
- 2–4 個完整 worked examples 或案例
- 常見錯誤與判斷提示
- 對應歷屆題目
- 由單元衍生的概念閃卡
- 書目、課程或原卷來源
- `draft / reviewed / published` 狀態

## 各科 MVP

### 資訊科技概論（第一優先，最快形成閉環）

- 以 8 個現有主題建立 8 份核心講義。
- 將 260 題標註 topic、difficulty、questionType。
- 246 題選擇題可進自動判分；14 題申論／程式題改用自評。不能從現有 `A`／`N/A` 答案值推測題型，必須依原題結構標註。
- 修正 60 張卡的 taxonomy；只保留可由講義或真題支持的卡。
- 路線：概念速讀 → 10 張概念卡 → 10 題主題題庫 → 錯題重練 → 完整年度模擬。
- MVP 驗收：8 主題皆有講義；每主題至少 5 張已審卡與 10 題可信題；至少 3 份完整年度卷可模擬。

### 資訊管理導論（第二優先，改做申論訓練）

- 以 5 個主題建立框架庫：定義、適用情境、分析步驟、案例、限制。
- 將 37 題拆成子題，標註考點與配分。
- 37 題題目本身已有原卷 SHA 鎖定，但目前解析沒有官方答案來源，必須標示為「參考擬答」並經人工審核。
- 現行題庫／模擬考的 A–E 操作不適用全部 37 題，未完成申論自評前不可宣稱能自動計分。
- 每題建立 rubric、答題骨架與一份 reviewed model answer；不能用選擇題式自動對錯。
- 路線：框架回想 → 案例判斷 → 限時列提綱 → rubric 自評 → 對照範例重寫。
- MVP 驗收：5 主題皆有框架講義；至少 20 題完成 rubric；每個主題至少 2 題完整示範。

### 統計學（先修申論互動，再上路線）

- 106–113 年當時尚未設統計考科，網站應明確顯示「該年未設考科」，不能呈現成缺卷。
- 114、115 年共 5 道大題（約 12 小題）已與 PDF 核對，可作為可信申論真題。
- 先支援「已作答 → 看解析 → 會／部分會／不會」自評；目前強迫選 A–E 會讓 5 題全部被判錯，必須先停用其自動計分與模擬考。
- 以 4 個主題建立公式表、條件判斷表與逐步例題。
- 現有 50 張卡重新對齊 topic，公式卡必須帶使用條件與常見誤用。
- 額外補至少 40 道站內基礎練習（每主題至少 10 題），讓使用者在進入申論真題前有可判分的練習層。
- 路線：公式喚回 → worked example → 同型變式題 → 計時真題 → 錯題重算。
- MVP 驗收：申論自評可用、40 題基礎練習完成、114／115 真題能正確記錄自評後，才開統計練習路線；不做選擇題式模擬計分。

## 共用系統

- Subject hub：顯示主題覆蓋率、可用練習與建置狀態。
- Lesson page：核心概念、例題、錯誤提示、對應真題。
- Practice route config：依科目設定步驟、份量、route 與開放條件。
- Progress：分開記錄「讀過、卡片熟練、題目正確、錯題已重練」。
- Validators：阻擋無效 topicId、無來源卡、缺答案題與不完整年度卷。

## 分期

0. 資料可信層：taxonomy、來源、狀態、validator。
1. 計概 MVP：利用現有 260 題先完成第一條非英文閉環。
2. MIS MVP：導入 rubric 與申論重寫流程。
3. 統計互動修正：申論自評、未設考科狀態、基礎練習內容。
4. 統計 MVP 與共用科目首頁路線。
5. 覆蓋率達標後，再把各科路線放到資管所首頁。

## 明確不上線的假功能

- 不先複製英文首頁卡片，避免連到沒有教材的流程。
- 不把沒有 provenance 的 160 張卡當作完整課程。
- 不讓 MIS／統計申論題使用 A–E 正確率或分數。
- 不為統計顯示不存在的 106–113 年缺卷警告。
- 不在年度卷尚未通過完整性與答案來源驗證時開啟正式模擬計分。
